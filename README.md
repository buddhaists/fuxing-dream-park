# 復興夢想主題遊樂園 — 新生報到與校園導覽（3D）

屏東縣復興國小 116 學年度小一新生的 3D 互動導覽網站。整座校園被比喻成一座溫暖的玩具微縮遊樂園：用低多邊形（low-poly）幾何、移軸模糊（tilt-shift）和暖色光影呈現。

## 快速開始

```bash
npm install
npm run dev        # 開發：http://localhost:5173
npm run build      # 打包成靜態網站到 dist/
npm run preview    # 預覽打包結果
```

`dist/` 資料夾可以直接上傳到任何靜態主機，例如 GitHub Pages 或學校主機。網站使用相對路徑，放在子目錄也能正常運作。

## 修改內容（不用改程式）

| 檔案 | 內容 |
|---|---|
| `src/data/campus.json` | 學校資訊、報到方式、設施與校園對照、路網節點、問答題目、小提醒 |
| `src/data/ui.json` | 所有按鈕和介面文字 |

- **設施**：`facilities[]`。`pos` 是 3D 座標 `[x, z]`，`node` 是導航時抵達的路網節點，`type` 決定使用哪一種模型。
- **路網**：`paths.nodes` 的座標格式是 `[x, z, 高度]`。在 `paths.edges` 加上 `{ "stairs": true }` 表示階梯，無障礙路線會自動避開；`{ "ramp": true }` 表示坡道。
- **問答**：每個選項的 `score` 對應設施 `id`，最後依總分推薦設施。
- 標示「（示意）」的處室位置是暫定配置，請依實際校園修改。

## 功能

- 🎟️ **入園門票**：親子適性小問答，依答案推薦第一個要去的設施，並直接帶路。
- 🏰 **設施資訊卡**：點 3D 模型或名稱標籤，就會顯示對應處室的說明。
- 🧭 **導航**：用 Dijkstra 演算法找出最短路徑，可選擇讓鏡頭沿路線跟隨，並附文字步驟說明。
- ♿ **無障礙動線**：一鍵顯示全區的坡道（綠色）和階梯（橘色）。導航時勾選「無障礙路線」就會避開所有階梯。
- 🎡 **摩天輪鳥瞰**：鏡頭跟著車廂轉一圈，到最高點時暫停，顯示全區標籤和對應處室。
- 📄 **純文字模式**（`text.html`）：用同一份資料檔產生，包含所有設施、報到資訊和每條路線的文字說明，適合螢幕閱讀器和列印。不支援 WebGL 的裝置會自動轉到這裡。
- ⚙️ **效能分級**：手機或低階裝置會自動使用省電畫質（關閉陰影和移軸模糊、降低解析度）。開場時如果偵測到幀率太低，也會自動降級。系統設定為「減少動態效果」時會自動遵循。

## 結構

```
src/
  data/        campus.json、ui.json（所有文字與資料）
  core/        graph.js（路網與最短路徑，3D 與文字版共用）、settings.js
  scene/       kit.js（材質與基本幾何）、facilities.js（各設施模型）、
               world.js（園區組裝）、routes.js（路線疊加層）、
               cameraRig.js（鏡頭）、postfx.js（移軸模糊）
  ui/          ui.js（面板與問答）、labels.js（3D 名稱標籤）
  main.js      3D 主程式
  text.js      純文字模式
```

所有幾何都由程式產生（方塊、圓柱、圓錐、二十面體），招牌文字也是用 Canvas 即時繪製，沒有使用任何外部 3D 模型檔或圖片。
